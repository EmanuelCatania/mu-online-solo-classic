# MU Online Solo Classic Documentation

Welcome to the documentation folder for **MU Online Solo Classic (Season 0.97k WebAssembly Edition)**.

## Guides & References

- **[Server Commands Guide](COMMANDS.md)** — Complete manual of all chat commands supported by the GameServer engine:
  - **Player Commands**: Stat allocation (`/str`, `/agi`, `/vit`, `/ene` + automated allocation), resets (`/reset`, `/reset auto`), grand resets (`/grandreset`), PK clearing (`/pkclear`), class evolution (`/evo`), multi-vault switching (`/ware`), fast teleportation (`/move`), inventory cleaner (`/clearinv`), request filtering (`/re`), and guild wars (`/war`, `/soccer`).
  - **Game Master (GM) & Administrator Commands**: Currency adjustments (`/addmoney`, `/submoney`), map moderation (`/gmove`, `/gmoveall`, `/chase`, `/bring`, `/disconnect`), item spawning (`/make`, `/makeset`, `/drop`), monster spawning (`/makemob`), player morphing (`/skin`), and server events (`/fireworks`, `/global`, `/tamastart`).
  - **Reference Tables**: Item groups (0–15), Armor set IDs, Excellent option bitmasks, Common monster IDs, Map numbers, and Move coordinates.
